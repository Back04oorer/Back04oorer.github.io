# Paper media

## Video previews

The Paper sections in `index.html` and `demo.html` use these video previews.
Playback is muted and loops only while a preview is on screen. Visitors can
pause each preview; reduced-motion preferences disable automatic playback.

- `touch-beaker.mp4`: user-provided Beaker Pouring filmed demonstration, copied
  from `Tactile Web/assets/contact-policy/beaker-filmed.mp4` on the user's Desktop.
- `core-pan.mp4`: https://aus.bot/research/core/assets/media/pan.mp4
- `nestdex-tongs.mp4`: https://aus.bot/research/nestdex/videos/tongs/01.mp4
- `triman-towel.mp4`: https://aus.bot/research/trimanpolicy/videos/towelhang/primary.mp4

Videos retain their original resolution and clip timing so manipulation details
remain visible in the larger layout and enlarged player. Only visible previews
load automatically. The enlarged player provides native playback controls and
continues from the preview’s current position. No task footage is synthesized.
